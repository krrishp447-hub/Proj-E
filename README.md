# Scout (Proj.E)

Scout is a creator discovery and intelligence platform designed for brands and agencies to find, rank, and evaluate creators based on authentic relevance and performance metrics.

## Project Structure

- **`web/`**: Next.js (App Router, TypeScript strict, Tailwind CSS v4, GSAP) web application featuring:
  - High-craft marketing site with fluid scroll animations
  - Interactive creator discovery engine and ranking demo (`/demo`)
  - Curated creator intelligence datasets and relevance scoring algorithms

## Getting Started

To run the web application locally:

```bash
cd web
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Testing & Verification

Inside the `web/` directory:

```bash
# Run unit tests
npm test

# Run TypeScript typechecks
npm run typecheck

# Run linter
npm run lint
```
